# Бот Telegram и запись — в Яндекс Облаке

Без своего сервера: бот работает как функция в Яндекс Облаке, заявки хранятся в базе YDB там же (серверы в России).
Сайт остаётся на GitHub Pages и отправляет заявки боту.

## Что умеет

**Клиентам:**
- записаться прямо в боте: пакет → день → время → имя → пожелания → «Записаться»;
- /price — прайс, /portfolio — фото и ссылка на портфолио, /contacts — контакты;
- /my — свои записи, отмена записи;
- ответ от бота, когда вы подтвердили или отменили съёмку (и для записей с сайта — если клиент нажал «Уведомления в Telegram»).

**Вам (фотографу):**
- каждая заявка — с сайта и из бота — приходит с кнопками «✅ Подтвердить» и «✖️ Отменить»,
  ссылкой на чат с клиентом и кнопкой «Написать клиенту»;
- отменённое окошко снова становится свободным, а если клиент сам отменил запись — вам придёт сообщение;
- /bookings — ближайшие записи;
- /close 7.11 — закрыть день (выходной, отпуск), /open 7.11 — открыть, /closed — список закрытых дней.

Бот узнаёт вас по username **@vaaaaaag**: напишите ему /start со своего аккаунта — и заявки будут приходить вам.

## Сколько стоит

0 ₽: бесплатных лимитов Яндекс Облака (1 млн вызовов функции и 1 млн операций с базой в месяц) хватает с большим запасом.
Банковская карта нужна только для регистрации платёжного аккаунта.

## Запуск (один раз, минут 20)

Удобнее с компьютера.

### 1. Бот в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — например «VAAAAAAG · запись на съёмку», адрес — например `vaag_ph_bot` (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AA…`. Это пароль бота — никому его не пересылайте, даже мне.
4. По желанию: `/setuserpic` — аватар бота.

### 2. Яндекс Облако

1. Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите через Яндекс ID.
2. Создайте **платёжный аккаунт** (попросит при первом входе): физлицо, карта. Деньги не спишутся.
3. Каталог `default` в облаке уже есть — в нём всё и создастся.

### 3. Ключ доступа для GitHub

1. В консоли откройте каталог `default` → слева **Identity and Access Management** → **Сервисные аккаунты** → **Создать сервисный аккаунт**.
2. Имя: `github-deploy`. Роли: **`editor`** и **`functions.admin`**. Создать.
3. Откройте этот аккаунт → **Создать новый ключ** → **Создать авторизованный ключ** → **Создать** → **Скачать файл с ключами**.

Файл `authorized_key.json` — это доступ к вашему облаку. Не пересылайте его и не кладите в репозиторий — только в секреты GitHub.

### 4. Секреты в GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**, два секрета:

| Name | Secret |
|------|--------|
| `YC_SA_KEY` | всё содержимое файла `authorized_key.json` (открыть Блокнотом, скопировать целиком) |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |

### 5. Запуск

1. Слейте запрос с изменениями в `main` (**Pull requests → Merge**), если ещё не слили.
2. **Actions** → **«Бот в Яндекс Облаке»** → **Run workflow**. Первый раз — минуты 3–5: создаются база и функция.
   В конце в отчёте будет ссылка на бота.
3. Сразу после этого сам пересоберётся сайт («Сайт на GitHub Pages»), и запись на сайте пойдёт через бота.
4. Напишите своему боту `/start` со своего аккаунта @vaaaaaag. Он ответит «Готово: вы — фотограф».
5. Проверьте: запишитесь на сайте и в боте, подтвердите и отмените заявки кнопками.

Дальше всё обновляется само: при изменениях в `landing/bot/` на `main` бот пересобирается, данные сохраняются.

## Если что-то не так

- **Сценарий в Actions красный** — откройте его: в тексте ошибки сказано, чего не хватает (секрет, роль, токен).
- **Бот молчит** — консоль Яндекс Облака → **Cloud Functions** → `vaag-bot` → **Логи**.
- **Заявки не приходят вам** — напишите боту `/start` именно с аккаунта @vaaaaaag. Если поменяете username,
  поменяйте `OWNER_USERNAME` в `.github/workflows/bot.yml`.
- Если бот недоступен, сайт сам переходит в простой режим: клиент получает готовый текст заявки и отправляет его вам в Telegram.

## Как устроено

| Файл | Что делает |
|------|-----------|
| `index.py` | точка входа функции: запросы сайта (`?r=content`, `slots`, `bookings`) и вебхук Telegram (`?r=tg`) |
| `bot.py` | заявки, диалог записи в боте, кнопки и команды фотографа |
| `core.py` | пакеты и расписание (из `server/app/seed.json`), проверка заявки, тексты сообщений |
| `store.py` | база YDB: таблицы `bookings`, `slots` (защита от двойной записи), `kv` |
| `deploy/` | развёртывание: вход в облако, база, функция, вебхук и меню бота |
| `tests/` | тесты: `python -m pytest tests` |

Пакеты, цены и расписание (время окошек, дни недели, на сколько дней вперёд) — в `landing/server/app/seed.json`
и `landing/shared/booking.ts` (сайт). Поменяли — на `main` бот и сайт обновятся сами.
