# Как выложить сайт в интернет

Сайт — набор обычных файлов (папка `dist` после сборки), поэтому подойдёт любой хостинг.
Ниже — Cloudflare Pages: бесплатно, быстро, и это тот же аккаунт, что и для сервера записи.

## Перед первой выкладкой

1. **Сервер записи.** Запустите его по инструкции в [`booking-worker/README.md`](booking-worker/README.md)
   и впишите его адрес в файл `.env.production` (пример — в `.env.example`).
   Без этого запись работает в тестовом режиме: клиент сам отправляет вам текст заявки.
2. **Политика конфиденциальности.** Впишите свои данные в `PRIVACY_OPERATOR` в `src/App.tsx`
   (ФИО, статус и ИНН, почта). Сейчас там заглушки в квадратных скобках.
3. **Домен для превью ссылок.** Если сайт будет не на `vaag-ph.ru`, поменяйте адрес
   в `og:url` и `og:image` в `index.html`.

## Выложить

Нужен компьютер с Node.js 18+. В папке `landing`:

```bash
npm install
npm run build
npx wrangler login                                       # один раз
npx wrangler pages deploy dist --project-name vaag-ph    # при первом запуске создаст проект
```

Wrangler покажет адрес вида `https://vaag-ph.pages.dev` — сайт уже работает.

После любых изменений — снова `npm run build` и последняя команда.

## Свой домен

1. В панели Cloudflare: **Workers & Pages → vaag-ph → Custom domains → Set up a custom domain**,
   впишите `vaag-ph.ru` и следуйте подсказкам (Cloudflare скажет, какие DNS-записи поставить у регистратора).
2. Проверьте, что адрес сайта есть в `ALLOWED_ORIGINS` в `booking-worker/wrangler.toml`
   (там уже есть `vaag-ph.ru` и `www.vaag-ph.ru`; для адреса `*.pages.dev` допишите его),
   и выложите сервер ещё раз: `npm run deploy` в папке `booking-worker`.

## Проверить после выкладки

- Откройте сайт с телефона и пролистайте до конца.
- Оформите тестовую запись — сообщение должно прийти в Telegram.
  Потом освободите это окошко (команда — в `booking-worker/README.md`).
- Отправьте ссылку на сайт себе в Telegram — должно появиться превью с картинкой.
