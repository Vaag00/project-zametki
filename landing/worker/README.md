# Бот Telegram и запись — в Cloudflare

Без своего сервера и бесплатно: бот работает как Cloudflare Worker, заявки хранятся в базе D1 там же.
Сайт остаётся на GitHub Pages и отправляет заявки боту.

## Что умеет

**Клиентам:**
- записаться прямо в боте: пакет → день → время → имя → пожелания → «Записаться»;
- /price — прайс, /portfolio — фото и ссылка на портфолио, /contacts — контакты;
- /my — свои записи, отмена записи;
- ответ от бота, когда вы подтвердили или отменили съёмку (и для записей с сайта — если клиент нажал «Уведомления в Telegram»).

**Вам (фотографу):**
- каждая заявка — с сайта и из бота — приходит с кнопками «✅ Подтвердить» и «✖️ Отменить»,
  ссылкой на чат с клиентом и кнопкой «Написать клиенту»;
- отменённое окошко снова становится свободным, а если клиент сам отменил запись — вам придёт сообщение;
- /bookings — ближайшие записи;
- /close 7.11 — закрыть день (выходной, отпуск), /open 7.11 — открыть, /closed — список закрытых дней.

Бот узнаёт вас по username **@vaaaaaag**: напишите ему /start со своего аккаунта — и заявки будут приходить вам.

## Сколько стоит

0 ₽ и без карты: бесплатного тарифа Cloudflare (100 000 запросов в день, 5 ГБ базы) хватает с большим запасом.

## Запуск (один раз, минут 15)

Удобнее с компьютера.

### 1. Бот в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — например «VAAAAAAG · запись на съёмку», адрес — например `vaag_ph_bot` (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `123456789:AA…`. Это пароль бота — никому его не пересылайте, даже мне.

### 2. Cloudflare

1. Зарегистрируйтесь на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) — нужна только почта, подтвердите её.
2. Account ID (`975b89a97441d9f64a28394e7fde8a1c`) уже вписан в `wrangler.toml` и `.github/workflows/*.yml`.
   Если смените учётную запись — замените его там (он виден в адресе страницы: `dash.cloudflare.com/<Account ID>/…`).

### 3. Токен доступа для GitHub

1. Справа сверху значок профиля → **My Profile** → **API Tokens** → **Create Token**.
2. Шаблон **Edit Cloudflare Workers** → **Use template**.
3. В **Permissions** нажмите **+ Add more** и добавьте: **Account** · **D1** · **Edit**.
4. **Continue to summary** → **Create Token** → скопируйте токен (он показывается один раз).

Этот токен — доступ к вашему Cloudflare. Не пересылайте его — только в секреты GitHub.

### 4. Секреты в GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**, два секрета:

| Name | Secret |
|------|--------|
| `CLOUDFLARE_API_TOKEN` | токен из шага 3 |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |

### 5. Запуск

1. Слейте запрос с изменениями в `main` (**Pull requests → Merge**), если ещё не слили — бот развернётся сам.
   Если уже слили: **Actions** → **«Бот в Cloudflare»** → **Run workflow**. В конце в отчёте будет ссылка на бота.
2. Сразу после этого сам пересоберётся сайт («Сайт на GitHub Pages»), и запись на сайте пойдёт через бота.
3. Напишите своему боту `/start` со своего аккаунта @vaaaaaag. Он ответит «Готово: вы — фотограф».
4. Проверьте: запишитесь на сайте и в боте, подтвердите и отмените заявки кнопками.

Дальше всё обновляется само: при изменениях в `landing/worker/` на `main` бот пересобирается, заявки сохраняются.

## Если что-то не так

- **Сценарий в Actions красный** — откройте его: в тексте ошибки сказано, чего не хватает (секрет, право токена).
- **Бот молчит** — панель Cloudflare → **Workers & Pages** → `vaag-bot` → **Logs**.
- **Заявки не приходят вам** — напишите боту `/start` именно с аккаунта @vaaaaaag. Если поменяете username,
  поменяйте `OWNER_USERNAME` в `landing/worker/wrangler.toml`.
- Из России Cloudflare иногда открывается с перебоями. Если сайт не может связаться с ботом, он сам переходит
  в простой режим: клиент получает готовый текст заявки и отправляет его вам в Telegram. Сам бот в Telegram работает в любом случае.

## Как устроено

| Файл | Что делает |
|------|-----------|
| `src/index.ts` | точка входа: запросы сайта (`?r=content`, `slots`, `bookings`) и вебхук Telegram (`?r=tg`) |
| `src/bot.ts` | заявки, диалог записи в боте, кнопки и команды фотографа |
| `src/texts.ts` | тексты сообщений |
| `src/store.ts`, `schema.sql` | база D1: `bookings`, `slots` (защита от двойной записи), `kv` |
| `deploy/` | развёртывание: база, Worker, вебхук и меню бота |
| `test/` | тесты: `npm test` |

Пакеты, цены и расписание общие с сайтом — `landing/shared/booking.ts`; фото для бота — из `landing/server/app/seed.json`.
Поменяли — на `main` бот и сайт обновятся сами.

Локально: `npm install`, файл `.dev.vars` с `TELEGRAM_BOT_TOKEN=…`,
`npx wrangler d1 execute vaag-bot --local --file schema.sql`, затем `npm run dev`.
